Propósito del Proyecto

Este sistema fue desarrollado con la finalidad de optimizar el registro, consulta y visualización de escuelas en la plataforma SEIEM, brindando una herramienta moderna, accesible y eficiente.

Tecnologías utilizadas

✔️ Django (framework web)
✔️ Python (lógica del servidor)
✔️ MongoDB (base de datos)
✔️ HTML5, CSS3 y JavaScript (interfaz)
✔️ Leaflet.js (mapa interactivo)
